How to install

  1. Tap Download APK and wait for it to finish.
  2. Open the downloaded file. If Android asks, allow Install unknown apps for your browser.
  3. If Play Protect warns about an unrecognised app, tap More details → Install anyway. This build comes directly from us, not from the Play Store.
  4. Open Arrow Puzzle and play!

Good to know

  1. This is a test build. In-app purchases may not work in it; everything else does.
  2. When Arrow Puzzle is on Google Play, uninstall this version first, then install it from the Play Store.
